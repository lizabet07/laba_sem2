# Лабораторная работа №2: Коллекция банковских счетов

## Цель работы

- Научиться работать с коллекциями объектов
- Понять разницу между моделью сущности и контейнером объектов
- Реализовать собственный контейнерный класс
- Освоить итерацию по объектам
- Реализовать базовые операции управления коллекцией

## Связь с ЛР-1

Класс `BankAccountCollection` является контейнером для хранения объектов `BankAccount` из лабораторной работы №1.

## Класс коллекции: BankAccountCollection

### Атрибуты

| Атрибут | Тип | Описание |
|---------|-----|----------|
| `_items` | `list[BankAccount]` | Внутренний список для хранения счетов |

### Методы

| Метод | Описание |
|-------|----------|
| `__init__(items=None)` | Конструктор коллекции |
| `add(item)` | Добавить счёт (с проверкой типа и дубликатов) |
| `remove(item)` | Удалить счёт из коллекции |
| `remove_at(index)` | Удалить счёт по индексу |
| `get_all()` | Вернуть список всех счетов |
| `find_by_owner_name(name)` | Поиск по имени владельца |
| `find_by_status(status)` | Поиск по статусу |
| `find_by_balance_range(min, max)` | Поиск по диапазону балансов |
| `get_active()` | Получить коллекцию активных счетов |
| `get_blocked()` | Получить коллекцию заблокированных счетов |
| `get_high_balance(threshold)` | Получить счета с балансом выше порога |
| `sort_by_balance(reverse=False)` | Сортировка по балансу |
| `sort_by_owner_name(reverse=False)` | Сортировка по имени |
| `sort(key, reverse=False)` | Универсальная сортировка |
| `__len__()` | Количество счетов |
| `__iter__()` | Итератор |
| `__getitem__(index)` | Доступ по индексу |
| `__str__()` | Строковое представление |
